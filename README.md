# Chiri AI Editor

A browser Markdown editor with an AI co-author. Select text (or just place the cursor in a paragraph), ask for a change, and the AI proposes it inline as a tracked change: old text struck through, new text beside it, plus a one-line reason. You accept, reject, or refine it. A review pass marks up the whole draft with up to six suggestions, the way a colleague would.
